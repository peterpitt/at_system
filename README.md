# 微型臺指期貨 (TMF) 自動化交易系統

> 使用永豐 **Shioaji API** 對微型臺指期貨進行自動化交易。
> 設計核心只有一句話：**先求生存，再談獲利 —— 把每一塊本金當成不可承受的損失來守護。**

這套系統是為「資金有限、輸不起」的情境量身打造。它寧可少賺、寧可不進場，
也不讓任何單一事件把帳戶打穿。所有風險參數都可調，但預設值刻意保守。

---

## ⚠️ 重要風險聲明（請務必讀完）

1. **期貨是高槓桿商品，可能在短時間內虧光本金，甚至產生超額損失（追繳）。**
2. 本系統**不保證獲利**。任何回測或邏輯都無法預測未來市場。
3. 程式交易仍可能因網路中斷、API 故障、行情跳空、滑價而虧損。
4. 72,000 元的資金對微型臺指而言**僅夠 1～2 口保證金**，緩衝極薄。
   本系統預設**硬性上限 1 口**，並在資金不足時自動拒絕下單。
5. **務必先以「模擬盤 (PAPER)」連續運行數週**，確認行為符合預期後，
   再考慮投入真實資金。
6. 你應自行對所有交易結果負責。請只投入「即使全部歸零也不影響生活」的資金。

## 🛡️ 內建的多層風險防線

| 防線 | 作用 | 預設值 |
|------|------|--------|
| 部位大小控制 | 依「單筆風險 ÷ 停損距離」算口數，再受保證金與硬上限夾擊取最小 | 風險 1% / 筆 |
| 每口強制停損 | 每個部位進場時即設定 ATR 停損，無停損不進場 | ATR × 2 |
| 每日虧損上限 | 當日（已實現＋未實現）虧損達上限 → 當日停止並平倉 | 3%（≈2,160 元）|
| 連續虧損熔斷 | 連續 N 筆虧損 → 當日停止 | 3 筆 |
| 總回撤永久鎖定 | 帳戶自起始資金回撤達上限 → 永久停止，需人工檢視 | 15%（≈10,800 元）|
| 保證金緩衝 | 下單要求剩餘資金 ≥ 保證金 × 1.15，預留追繳空間 | ×1.15 |
| 收盤前強制平倉 | 不留倉過夜，避免夜盤/隔日跳空風險 | 13:25 |
| 實單雙重確認 | 須同時設定 `LIVE` 與確認鎖才動用真實資金 | 預設關閉 |
| Kill switch | 建立 `KILL_SWITCH` 檔即立刻停止並平倉 | — |

## 📐 交易策略

**EMA 趨勢跟隨 + ATR 動態停損／停利**（保守、邏輯透明、不易過度擬合）

- **進場**：EMA 快線與慢線黃金交叉做多、死亡交叉做空。
- **停損**：進場價 ∓ ATR × 2（依市場波動自適應）。
- **停利**：進場價 ± ATR × 3（風報比 1.5，維持正期望值）。
- **出場**：觸及停損／停利、趨勢反向交叉、或收盤前強制平倉。
- 同時只持有**單一方向、單一部位**。

> 策略可在 `.env` 中調整參數，或替換 `src/strategy.py`。風控與下單邏輯與策略解耦。

## 🚀 安裝與使用

### 1. 安裝套件
```bash
pip install -r requirements.txt
```

### 2. 設定金鑰
```bash
cp .env.example .env
# 編輯 .env，填入永豐 API 金鑰、帳號、憑證路徑與密碼
```
將永豐憑證 `Sinopac.pfx` 放到 `.env` 指定的路徑。
**`.env` 與 `*.pfx` 已被 `.gitignore` 忽略，切勿提交！**

### 3. 連線檢測（只讀，不下單）
```bash
python scripts/check_connection.py
```
確認能登入、解析 TMF 合約、取得保證金與餘額。

### 4. 模擬盤試跑（強烈建議先做）
```bash
python main.py --dry-run        # 持續運行模擬
python main.py --once --dry-run # 只跑一輪，檢視決策
```

### 5. 正式啟動
- 模擬盤：`.env` 設 `TRADING_MODE=PAPER`，執行 `python main.py`
- **實單（真實資金）**：需在 `.env` **同時**設定
  ```
  TRADING_MODE=LIVE
  CONFIRM_LIVE_TRADING=I_UNDERSTAND_THE_RISK
  ```
  否則系統會自動降級為模擬盤以保護你的本金。啟動後另有 10 秒倒數可中止。

### 緊急停止
```bash
touch KILL_SWITCH    # 系統下一輪即平倉並永久停止
```
或直接 `Ctrl+C`，引擎會在關閉前清空部位。

## 🗂️ 專案結構

```
at_system/
├── main.py                  # 進入點：載入設定、安全確認、啟動引擎
├── config.py                # 設定載入與驗證（不合理即拒絕啟動）
├── requirements.txt
├── .env.example             # 設定範本
├── src/
│   ├── risk_manager.py      # ★風控核心：部位大小、各項防線
│   ├── strategy.py          # EMA + ATR 趨勢策略
│   ├── trader.py            # 主交易迴圈，串接各模組
│   ├── broker.py            # 永豐 Shioaji 封裝（登入/合約/下單/帳務）
│   ├── position.py          # 部位與損益追蹤
│   ├── notifier.py          # Telegram / 日誌通知
│   ├── config_types.py      # 引擎層精簡設定
│   └── logger.py            # 統一日誌
├── scripts/
│   └── check_connection.py  # 連線自我檢測（只讀）
└── tests/
    ├── test_risk_manager.py     # ★風控測試（守護本金的驗證）
    └── test_strategy_position.py
```
